# Frontend Restaurante

Interfaz de usuario del sistema de gestión de restaurante. Desarrollado con HTML, CSS y JavaScript Vanilla, consume los microservicios del backend mediante Fetch API.

## Páginas

| Página | Descripción |
|---|---|
| login.html | Inicio de sesión |
| mesas.html | Gestión de mesas y reservas |
| productos.html | Catálogo de productos |
| pedidos.html | Gestión de pedidos |

## Requisitos

- Tener los 4 microservicios del backend corriendo
- Navegador web

## Pasos para correr en la U

### 1. Clonar el repositorio
git clone https://github.com/Camilo699/Frontend-restaurante.git

### 2. Abrir el proyecto
- Abrir la carpeta en VS Code
- Abrir el archivo index.html en el navegador
- O abrir directamente pages/login.html
